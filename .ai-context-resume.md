# Contexto do Projeto - Tech Challenge Fase 3 (Sistema de Hospital)

## 1. User Intent & Arquitetura
- Desenvolvimento de um sistema de gestão hospitalar modular baseado em microsserviços containerizados.
- Aplicação de Clean Code, princípios SOLID, Java 25, Spring Boot 3.4.x e estratégia de "Polyrepo".

## 2. Pilha de Infraestrutura Atual (Docker Compose)
- **HashiCorp Consul:** Service Discovery (Porta 8500)
- **PostgreSQL:** Banco de dados relacional centralizado / bancos específicos (`hospital_db`, `keycloak_db`) (Porta 5432)
- **Keycloak:** IAM / Autenticação e Segurança (Porta 8080)
- **RabbitMQ:** Mensageria assíncrona (Porta 5672 / Management Porta 15672)
- **Grafana + Loki:** Pilha moderna, leve e 100% gratuita de observabilidade e logs (Grafana na Porta 3000, Loki na Porta 3100).
  *(O Splunk foi totalmente removido do ambiente para liberar espaço e evitar custos/limitações de licença).*

## 3. Progresso Realizado
- Repositório `hospital-infrastructure` estruturado e validado.
- Todos os containers de infraestrutura subidos com sucesso no Ubuntu e testados (`docker ps` 100% verde).
- Correção de dependência do banco `keycloak_db` realizada no PostgreSQL.
- Limpeza de imagens antigas e otimização do espaço em disco efetuadas.

## 4. Próximos Passos (Para Amanhã)
- Iniciar a criação do primeiro microsserviço de negócio: **Serviço de Agendamento (Scheduling Service)**.
- Configuração do projeto Spring Boot com Java 25, DTOs em `record`, migrações com Flyway e registro no Consul.
